# Código de conduta

Este projeto é um espaço de aprendizado. Esperamos que todas as pessoas que participam dele, em issues, pull requests ou qualquer outro canal:

- Tratem as outras com respeito e cordialidade, independentemente de experiência, origem, gênero, identidade, aparência, religião ou qualquer outra característica pessoal.
- Façam críticas ao **trabalho**, nunca à pessoa, e de forma construtiva.
- Aceitem sugestões e correções com boa vontade.
- Ajudem quem está começando.

Não são aceitos: ofensas, assédio, comentários discriminatórios, ataques pessoais, nem a divulgação de informações privadas de alguém sem permissão.

Problemas de conduta podem ser comunicados aos autores do projeto (veja o README). As mensagens serão tratadas com sigilo, e quem descumprir estas regras poderá ser removido das discussões do projeto.

Este código é inspirado no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
